# HackerRank 3rd Semester Portfolio

A beginner-friendly collection of Python solutions from my 3rd semester programming activity on HackerRank.

## Language

Python 3

## Problems and complexity

| Problem | Time complexity | Space complexity |
| --- | --- | --- |
| [Diagonal Difference](https://www.hackerrank.com/challenges/diagonal-difference/problem) | O(n) | O(n²) for the input matrix; O(1) auxiliary |
| [Dynamic Array](https://www.hackerrank.com/challenges/dynamic-array/problem) | O(n + q) | O(n + q) |
| [Time Conversion](https://www.hackerrank.com/challenges/time-conversion/problem) | O(1) | O(1) |
| [Compare the Triplets](https://www.hackerrank.com/challenges/compare-the-triplets/problem) | O(1) | O(1) |
| [Sparse Arrays](https://www.hackerrank.com/challenges/sparse-arrays/problem) | O(S + Q) average | O(U + q) |

Here, `n` is the matrix dimension or number of sequences as applicable, and `q` is the number of queries. For Sparse Arrays, `S` is the total number of characters in the input strings, `Q` is the total number of characters in the query strings, and `U` is the number of distinct input strings. Sparse Arrays uses a hash map, so its lookup complexity is average-case.

## Run locally

Install Python 3, open a terminal in the repository root, and run any solution with `python` followed by its path:

```text
python "Diagonal-Difference/solution.py"
python "Dynamic-Array/solution.py"
python "Time-Conversion/solution.py"
python "Compare-the-Triplets/solution.py"
python "Sparse-Arrays/solution.py"
```

When prompted, enter the input in the format shown on the corresponding HackerRank problem page. On Windows, finish entering input with **Ctrl+Z**, then **Enter**.
